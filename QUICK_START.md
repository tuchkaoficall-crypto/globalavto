### 2. Установите таблицы БД

```bash
cd server
npm run setup-monitoring
```

Вы увидите:
```
✅ Таблица activity_logs создана
✅ Индексы созданы
🤖 Telegram бот готов к работе!
```

### 3. Протестируйте бота

```bash
npm run test-telegram
```

Проверьте Telegram - придет 7 тестовых уведомлений.

### 4. Запустите сервер

```bash
npm start
```

Должно появиться:
```
✅ Server running on http://localhost:5000
🤖 Telegram command bot started
📊 Daily stats scheduled for ...
```

### 5. Проверьте команды бота

Откройте Telegram и отправьте боту:
- `/start` - приветствие
- `/help` - список команд
- `/stats` - статистика за 24 часа
- `/ping` - проверка связи

## 🔍 Проверка работы

   ```
   📱 Устройство: Desktop
   ```

## 🐛 Если что-то не работает

### Бот не отвечает на команды
```bash
# Проверьте .env
cat .env | grep TELEGRAM

# Перезапустите сервер
npm start
```

### Уведомления не приходят
1. Проверьте, что бот не заблокирован в Telegram
2. Напишите боту `/start` первый раз
3. Проверьте логи сервера

### База данных
```bash
# Если таблица не создалась
npm run setup-monitoring

# Проверка подключения к БД
psql -U postgres -d globalavto -c "SELECT COUNT(*) FROM activity_logs;"
```
