## 🐛 Troubleshooting

### Проблема: Бот не отвечает на команды

**Проверьте:**
- [ ] Сервер запущен (`npm start`)
- [ ] Строка "🤖 Telegram command bot started" в логах
- [ ] TELEGRAM_BOT_TOKEN в `.env` корректен
- [ ] TELEGRAM_CHAT_ID в `.env` корректен
- [ ] Написали правильному боту
- [ ] Отправили `/start` хотя бы раз

**Решение:**
```bash
# Перезапустить сервер
npm start
```

### Проблема: Уведомления не приходят

**Проверьте:**
- [ ] Бот не заблокирован
- [ ] Отправлен `/start` боту
- [ ] TELEGRAM_CHAT_ID соответствует вашему ID
- [ ] Нет ошибок в логах сервера

**Решение:**
```bash
# Тест уведомлений
npm run test-telegram
```

### Проблема: Таблица не создается

**Проверьте:**
- [ ] PostgreSQL запущен
- [ ] База данных `globalavto` существует
- [ ] Настройки в `.env` корректны:
  ```
  DB_HOST=localhost
  DB_PORT=5432
  DB_NAME=globalavto
  DB_USER=postgres
  DB_PASSWORD=lolgame228232
  ```

**Решение:**
```bash
# Повторная установка
npm run setup-monitoring
```

### Проблема: Ошибка при запуске

**Проверьте:**
- [ ] Установлены зависимости: `npm install`
- [ ] Порт 5000 свободен
- [ ] Файл `.env` существует

**Решение:**
```bash
npm install
npm start
```
